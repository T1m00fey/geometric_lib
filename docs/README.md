## Описание

Эта библиотека написана для вычисления площади и периметра геометрических фигур.

Поддерживаются следующие фигуры:
- Circle
- Rectangle
- Square
- Triangle


## Математические формулы:

## Площадь

- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = ah / 2


## Периметр

- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c


## Примеры вызова

circle.area(6)
circle.perimeter(7)

rectangle.area(6, 7)
rectangle.perimeter(6, 7)

square.area(6)
square.perimeter(7)

triangle.area(6, 7)
triangle.perimeter(1, 2, 3)
